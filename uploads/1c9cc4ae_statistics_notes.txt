STATISTICS NOTES
================

What is Statistics?
Statistics is the science of collecting, analyzing, interpreting, and presenting data.
It forms the mathematical foundation of Machine Learning and Data Science.

Two Branches:
1. Descriptive Statistics - Summarizes data
   - Mean, Median, Mode
   - Variance, Standard Deviation
   - Histograms, Box plots

2. Inferential Statistics - Draws conclusions from data samples
   - Hypothesis Testing
   - Confidence Intervals
   - Regression Analysis

Key Concepts:

Mean: Average value of a dataset
  Formula: Sum of all values / Number of values

Variance: How spread out the data is from the mean
  High variance = data is spread wide
  Low variance = data is close to the mean

Standard Deviation: Square root of variance
  Used in ML to normalize features (Z-score normalization)

Normal Distribution (Bell Curve):
  - Most real-world data follows this shape
  - 68% of data falls within 1 standard deviation
  - 95% falls within 2 standard deviations
  - Used in neural network weight initialization

Probability:
  - Foundation of Naive Bayes classifier
  - Used in Logistic Regression output (0 to 1)
  - Bayes Theorem: P(A|B) = P(B|A) * P(A) / P(B)

Hypothesis Testing:
  - Null Hypothesis (H0): No significant relationship exists
  - Alternative Hypothesis (H1): A relationship does exist
  - P-value < 0.05 means result is statistically significant
  - Used to validate ML model improvements

Correlation:
  - Measures relationship between two variables
  - Range: -1 to +1
  - +1 = perfect positive relationship
  - -1 = perfect negative relationship
  - 0 = no relationship
  - Used in feature selection for ML models

How Statistics Connects to Machine Learning:
  - Linear Regression is a statistical method
  - Model evaluation uses statistical metrics
  - Data preprocessing uses statistical normalization
  - Outlier detection uses standard deviation rules
